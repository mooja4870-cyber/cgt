# 상속·증여 검증 플랜 (주택)

## 목적
- 상속/증여 계산 결과의 신뢰도를 배포 전 정량 검증한다.
- 일반 사용자 배포 전에 오판 가능 구간을 사전 식별한다.

## 배포 원칙
- 상속/증여는 최소 20~30건 검증 완료 전 공개 배포 금지.
- 검증 전에는 앱 내 문구를 "참고용/베타"로 유지.

## 테스트 범위
- 취득 유형: 상속, 증여
- 핵심 로직:
  - 취득일/양도일 기준
  - 장기보유특별공제 계산
  - 1세대1주택 비과세 판정
  - 고가주택(12억 초과) 안분
  - 증여 이월과세 적용/배제
  - 다주택 중과세율 분기

## 테스트 데이터 준비
- 매매계약서/증여계약서/상속 관련 일자 근거
- 등기부등본 (접수일 확인)
- 취득가액/양도가액/필요경비 증빙
- 조정대상지역 여부 및 주택 수 정보

## 검증 방법
1. 케이스 입력값을 앱에 입력
2. 앱 산출값 기록
3. 기준값(세무사 검토 또는 수기 계산표)과 비교
4. 오차 및 실패 원인 기록
5. 수정 후 동일 케이스 회귀 테스트

## 합격 기준
- 필수 분기 케이스 100% 실행
- 총 세액 오차 허용치: 원칙적으로 0 (반올림 규칙 차이는 별도 기록)
- FAIL 케이스 0건일 때만 공개 배포

## 우선순위 높은 케이스
- 상속: 동일세대/비동일세대, 보유·거주 기간 경계값
- 증여: 5년 내 양도/5년 초과 양도, 이월과세 비교과세
- 공통: 12억 경계값, 2주택/3주택 분기

## 운영 권고
- Play Console 내부 테스트(Closed Track)로 먼저 배포
- 사용자 신고로 사후 수정하는 방식은 세무 앱 특성상 비권장
