# 양도세 AI 계산기 (CGT)

이 README는 앱 첫 진입 시 표시되는 **사용 가이드(1/5 ~ 5/5)** 내용을 중심으로 정리한 문서입니다.

## 1. 앱 소개
부동산 양도 시 필요한 양도소득세를 빠르고 정확하게 계산하는 앱입니다.

### 이 앱으로 할 수 있는 것
- 양도차익 및 세액 자동 계산
- 1세대 1주택 비과세 여부 자동 판단
- 장기보유특별공제 자동 적용
- 다주택자 중과세율 반영
- 상속·증여 취득 특례 계산

### 꼭 확인
- 계산 결과는 참고용 추정치입니다.
- 실제 신고 전 세무사 상담이 필요합니다.

### 현재 지원
- 주택(아파트, 단독, 다가구 등)
- 분양권/건물/토지는 준비 중

## 2. 입력 순서 (3단계)
### 1) 기본정보 탭
- 취득 종류 선택(매매/상속/증여)
- 취득일·양도일 입력
- 조정대상지역·주택 수 선택

### 2) 가액·경비 탭
- 양도가액·취득가액 입력
- 필요경비 입력(취득세·중개수수료 자동계산)
- 환산취득가액 모드 지원

### 3) 계산결과 탭
- 양도차익 → 장특공제 → 과세표준 → 세율 → 납부세액 순서로 결과 표시
- 비과세 해당 시 자동 안내

### 자동 저장
- 입력값은 자동 저장되어 새로고침/홈 이동 후에도 유지됩니다.

## 3. 취득일·양도일 입력 기준
### 매매 원칙
- 잔금(대금) 청산일을 기준으로 입력
- 잔금 전 등기이전 완료 또는 잔금일 불분명 시 등기접수일 기준
- 근거: 소득세법 §98, 시행령 §162

### 상속/증여
- 상속: 상속개시일(피상속인 사망일)
- 증여: 증여 등기접수일

### 주의
- 계약일은 취득일이 아닙니다.

## 4. 비과세·절세 핵심
### 1세대 1주택 기본 요건
- 1세대 1주택 + 보유 2년 이상(양도일 기준)
- 취득 시 조정대상지역이면 거주 2년 요건 추가

### 12억 초과 고가주택
- 양도가액 12억 원 초과분에 대해서만 과세
- 비과세 + 과세 안분 적용

### 장기보유특별공제
- 보유 연 2%, 거주 연 2%
- 최대 80% 공제 가능(1세대1주택 고가주택 기준)

### 다주택자 중과
- 2026년 5월 10일 이후 양도분부터 적용 재개
- 2주택 +20%p, 3주택 이상 +30%p

## 5. 시작 전 준비물
### 필수
- 매매계약서(취득·양도 잔금일 확인)
- 등기부등본(등기접수일 확인)

### 권장
- 취득세 납부 영수증
- 부동산 중개수수료 영수증

### 필요 시
- 기준시가 자료(국토부 공시지가 등)
